**プロジェクト**: voice-fep  
**バージョン**: 0.1.0  
**著者**: Subutomo Dev  
**最終更新**: 2026-10-31

---

## 1. 概要・目的

Windows 上で常駐し、ホットキー（F8）のトグルにより音声録音→文字起こし→アクティブウィンドウへの自動ペーストを行う FEP（Front-End Processor）ツール。  
IME の代替ではなく「話しかけると書き起こしてくれる補助ツール」として動作する。

---

## 2. アーキテクチャ

```
[マイク]
   |
   | 16kHz PCM (sounddevice)
   v
[録音モジュール]  <--F8 押下でトグル制御 (pynput)
   |
   | WAV bytes (メモリ内のみ、ディスク不要)
   v
[バックエンドルーター]
   |
   +-- BACKEND=gemini       --> [Gemini API (google-genai)]
   +-- BACKEND=cloudflare   --> [Cloudflare Workers AI]
   +-- BACKEND=local_whisper--> [faster-whisper (ローカル)]
   |
   | テキスト (補正済み書き起こし)
   v
[ペーストモジュール]
   |
   | フォーカスを保持したまま pyautogui.hotkey('ctrl','v') を発行
   v
[アクティブウィンドウ]

[フローティングインジケータ] -- tkinter 最小ウィンドウ (右上固定)
   録音中: 赤丸●  /  待機中: 灰丸○  /  処理中: 黄丸◎
```

## 3. モジュール設計

### 3.1 main.py
- エントリポイント。tkinter ループと pynput リスナーを別スレッドで起動。
- F8 キーイベントで `recorder` のトグルを呼び出す。
- 録音完了コールバックで `backend_router` → `paste_module` を順次実行。

### 3.2 recorder.py（将来分割用）
- `sounddevice.InputStream` を使用。サンプルレート 16000Hz、モノラル。
- 録音データは `numpy.ndarray` としてメモリに蓄積し、終了時に WAV bytes に変換。
- ディスクへの書き出しは行わない（セキュリティ要件）。

### 3.3 backend_router.py（将来分割用）
- `.env` の `BACKEND` 変数で切り替え。
- 各バックエンドは `transcribe(wav_bytes: bytes) -> str` インターフェースを持つ。

### 3.4 paste_module.py（将来分割用）
- `pyperclip.copy(text)` でクリップボードへ書き込み。
- `pyautogui.hotkey('ctrl', 'v')` でペースト。
- ペースト後にクリップボードをクリア（セキュリティ要件）。

## 4. バックエンド詳細

### 4.1 Gemini API（本命）
- SDK: `google-genai` (google-generativeai の後継)
- モデル: `gemini-2.0-flash`（`.env` の `GEMINI_MODEL` で上書き可）
- 入力: WAV bytes を base64 エンコードしてインライン送信
- API キーは `os.environ` 経由のみで参照。ハードコード禁止。

### 4.2 Cloudflare Workers AI（フォールバック）
- モデル: `@cf/openai/whisper`
- REST API 経由。`CLOUDFLARE_API_KEY` + `CLOUDFLARE_ACCOUNT_ID` を使用。

### 4.3 ローカル Whisper（オフライン）
- ライブラリ: `faster-whisper`
- モデル: `small`（初回のみダウンロード）
- ネットワーク不要。プライバシー最優先時の選択。

## 5. プロンプト仕様

### 5.1 システムプロンプト（Gemini 送信時）

```
あなたは日本語音声の書き起こし専門アシスタントです。
以下のルールを厳守してください。
- 挨拶・返答・確認・説明は一切出力しない。
- 書き起こしテキストのみを返す。
- 言い淀み（「えーと」「あの」「まあ」等）は除去する。
- 文脈から適切な漢字・熟語に変換する（例: "きょねん" → "去年"）。
- 助詞・接続詞の補正を行い自然な日本語にする。
- 専門用語は文脈から推定して正確に表記する（例: "くらうど" → "クラウド"）。
- 出力はテキストのみ。余分な記号・括弧・マークダウン不要。
```

### 5.2 プロンプト変更ポリシー
プロンプトは `PROMPT_TEMPLATE` 定数として `main.py` 冒頭に配置し、  
変更時は必ずコードレビューを経てコミットする。

## 6. UI: フローティングインジケータ

- tkinter による透過ウィンドウ（約 80×80px）
- 常に最前面（`topmost=True`）、右上端に固定
- 状態アイコン:
  - 待機中: ○（灰）
  - 録音中: ●（赤）+ 点滅
  - API送信中: ◎（黄）
  - エラー: ×（橙）
- クリックしても何も起きない（ホットキーのみで操作）

## 7. セキュリティ・ハーネス制約

| 制約 | 詳細 |
|------|------|
| APIキーのハードコード禁止 | `.env` + `python-dotenv` 経由のみ。コードに直接記述した場合は PR ブロック |
| 音声データのディスク書き出し禁止 | メモリ内処理のみ。`*.wav` は `.gitignore` に列挙済み |
| ログへのキー・音声テキスト出力禁止 | ログレベルは INFO 以上。DEBUG ログも音声内容は含めない |
| テストループ上限 | 失敗したテストの自動修正は最大 3 回で停止し、人間にエスカレーション |
| Git コミット/Push は人間が承認 | Claude Code は提案のみ。`--no-verify` は使用禁止 |
| クリップボードクリア | ペースト直後に `pyperclip.copy("")` を実行 |
